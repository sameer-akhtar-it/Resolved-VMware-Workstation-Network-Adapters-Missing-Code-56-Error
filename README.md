# Resolved-VMware-Workstation-Network-Adapters-Missing-Code-56-Error
After reinstalling/repairing VMware Workstation, the virtual network adapters (VMnet1 and VMnet8) showed yellow exclamation marks in Device Manager with Code 56 ("Windows is still setting up the class configuration for this device"). In addition, PuTTY timed out when trying to connect to the Linux VM.
